# Experiencia Profesional

## LabIOS - Sistema de Gestión de Inventario y Préstamos
**Ciudad de México** | **Full-Stack Developer** | **Ene 2024 - Actualidad**

• Desarrollo completo de sistema web full-stack para gestión de inventario de equipos y control de préstamos, implementando arquitectura separada frontend-backend con React SPA y API REST en PHP, mejorando la escalabilidad y mantenibilidad del sistema.

• Diseño e implementación de sistema de autenticación basado en tokens JWT con middleware de seguridad, protección de rutas mediante React Router y persistencia de sesión con localStorage, garantizando acceso seguro a todas las funcionalidades del sistema.

• Optimización de rendimiento mediante code splitting con React Router, lazy loading de componentes y consultas SQL optimizadas con agregaciones en servidor (GROUP BY, COUNT), reduciendo el tiempo de carga inicial y mejorando la experiencia del usuario.

• Implementación de dashboard interactivo con visualización de datos en tiempo real utilizando Chart.js y React-ChartJS-2, incluyendo gráficos de barras horizontales personalizados que muestran estadísticas de equipos por categoría y métricas de préstamos activos.

• Desarrollo de API REST completa con PHP 8.x y PDO, implementando prepared statements para prevenir SQL injection, validación de inputs en backend, configuración de CORS y manejo robusto de errores con timeouts de 10 segundos y mensajes descriptivos.

• Implementación de sistema de roles y permisos (superadministrador, administrador, viewer) con control de acceso granular, gestión de administradores y configuración del sistema mediante panel de administración integrado.

• Creación de módulos completos de gestión: inventario de equipos con estados (disponible, prestado, mantenimiento), sistema de préstamos y devoluciones con seguimiento de fechas, registro de usuarios con búsqueda avanzada y sistema de reportes de equipos con estados de seguimiento.

• Optimización del código mediante eliminación de componentes no utilizados, reorganización de estructura de carpetas por funcionalidad, limpieza de dependencias npm y mejora de la organización del proyecto para facilitar mantenimiento y escalabilidad.

• Tech stack: React 19, React Router DOM, Vite, Tailwind CSS, Chart.js, PHP 8.x, MySQL/MariaDB, PDO, Apache, Git, GitHub.
